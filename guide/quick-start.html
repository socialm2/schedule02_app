Quick Start

SMC Fair Shift — 빠른시작가이드 (v0.4)

대상 병동 리더 소요시간 처음이면 5분, 익숙해지면 1분

전체 설명은 「사용자매뉴얼」에, 인쇄해서 옆에 두고 보는 요약은 「원페이지」에 있다. 이 문서는 처음 써보는 리더를 위해 핵심 단계만 압축했다.

1링크 접속

받은 링크를 브라우저로 열면 끝 — 설치 없음. 브라우저 전용판은 처음 접속 시 비밀번호를 물어본다 (배포 담당자에게 받은 접속 비밀번호 입력). 화면엔 이미 샘플 병동 데이터가 채워져 있으니, 처음엔 그대로 "근무표 생성"을 눌러봐도 되고, 우리 병동 데이터로 바로 바꿔도 된다.

2입력 파일 올리기 (또는 직접 입력)

화면 상단 입력①(병동인력표)이 핵심이다 — 업로드 버튼 옆 양식 버튼을 누르면 실제 40명 규모 예시 파일(자세한 설명 포함)을 받을 수 있다. 이걸 다운받아 우리 병동 값으로 고친 뒤 업로드 버튼으로 올리면 화면 아래 표들이 자동으로 채워진다. 파일 없이 화면에서 표를 직접 채워도 된다. 입력②(전월근무표)·입력③(원티드표)· 입력④(인원표)는 선택 사항 — 없으면 그냥 비워두고 생성하면 된다.

3최소인력 · 원티드 확인

근무별(D/E/N/prn) 최소 필요 인원과, 이번 달 직원들이 신청한 휴무·근무 희망을 화면에서 확인·수정한다.

4"근무표 생성" 클릭

인원이 많은 병동(40명대)은 최대 2분 정도 걸릴 수 있다 — 진행 중 안내 화면이 뜨니 창을 닫지 말고 기다리면 된다.

5결과 확인

근무표 그리드와 검증 요약(하드 위반 건수, 신청 반영 현황)이 함께 나온다. 하드 위반이 남아있다면 프로그램 오류가 아니라 "이 입력으로는 규칙을 100% 못 지켰다"는 정직한 신호다 — 자세한 이유는 「사용자매뉴얼 §10 FAQ」 참고.

6필요하면 직접 수정 → 재생성

그리드 셀을 직접 클릭해 바꾸면 그 칸은 스테이징(주황 점선)되고, "피드백 확인" → "재생성 적용"을 누르면 고정한 칸은 그대로 둔 채 나머지만 다시 맞춰준다. 인원이 많으면 재생성도 생성만큼 시간이 걸릴 수 있다. "입력으로 돌아가기"를 누르면 수정 내역이 전부 사라지고 처음부터 다시 시작하니 주의.

7"근무표 엑셀" 다운로드 → 부서 배포

완성본을 엑셀로 받아서 부서원들에게 전달한다. 앱 자체는 리더만 쓰고, 나머지 직원은 이 엑셀 파일만 받아보면 된다. "인원표(갱신본)"도 함께 받아 보관해두면, 다음 달 입력④로 다시 올렸을 때 누적 통계가 이어진다.

기억해둘 것 — 브라우저 전용판은 데이터가 그 폰·PC 안에만 저장된다. 다른 기기에서 이어서 못 보니, 확정한 근무표는 꼭 엑셀로 다운로드해서 따로 보관해두자.

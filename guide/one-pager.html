SMC Fair Shift — 원페이지 요약

v0.87 · 파트장용 1장 요약

사용 순서

  1. 링크 접속 — 설치 없이 브라우저로 열면 끝(주소는 꼭 https로 — 아니면 비밀번호 확인이 안 된다). 입력 화면("1. 기본 사항 입력") 상단에는 입력 데이터가 서버로 전송되지 않고 이 브라우저에서 처리된다는 안내(공용 기기·화면공유·다운로드 파일 주의 포함)가 항상 표시된다. 처음엔 샘플 병동(설정·근무인력·명단)이 이미 채워져 있다 — 첫 달엔 오른쪽 "처음 쓰는 달의 첫 작업"부터. 폰이면 브라우저 메뉴의 '홈 화면에 추가'(iPhone: 공유 · Android: ⋮)로 아이콘을 만들어 두면 주소를 다시 치지 않아도 된다.
  2. 설정·근무인력 입력 — 화면에서 직접 친다(올릴 파일 없음). 월최대야간·연속근무제한· 야간목표와 근무별(D/E/N/prn) 요일별 필요 인원을 채우면 이 브라우저에 저장돼 다음에 열 때 그대로 뜬다. 연월만은 저장하지 않고 열 때마다 항상 다음 달로 잡힌다 — 만드는 것은 늘 다음 달 근무표이기 때문이다. 공용 PC면 다 쓴 뒤 근무정보 묶음 맨 아래의 저장한 설정 지우기를 누른다 — 한 번 확인을 묻고 모든 칸을 빈칸으로 비운다(샘플 값으로 돌아가는 것이 아니라, 우리 병동 값으로 새로 채워 넣으라는 뜻). 샘플 값이 다시 필요하면 바로 아래 샘플 값으로 되돌리기. 칸을 비운 채 생성하면 몇 칸이 비었는지 한 줄로 알리고 첫 빈 칸으로 간다. 연속근무제한은 3 이상만 받는다(보통 5) — 2 이하는 생성을 누르면 반려된다. 공휴일·월신청상한 칸은 없다 — 공휴일은 코드가 2040년까지 자동으로 계산해서 채운다.
  3. 입력① 올리기 — 인원(직급·숙련도·가능근무·야간리더·비고·전입·전입일)과 원티드 신청을 파일 하나로 받는다. 첫 달엔 필수(우리 명단이 이 파일로만 들어간다 — 안 올리면 샘플 명단으로 만들어진다). 업로드 칸 옆 "양식(다운로드)"으로 현재 명단·연월에 맞는 양식을 받아 채워 올린다. 날짜 칸은 OCS에서 그대로 복사해 붙여넣어도 된다(X = 원티드오프, 근무코드 뒤 * = 원티드 근무). 만드는 달은 화면의 연월이다 — 파일 연월이 다르면 연월 칸 아래에 "파일과 화면의 연월이 다릅니다" 카드가 뜨고 신청은 날짜의 '일'만 보고 화면 달에 적용한다. 파일 쪽이 맞으면 카드의 "화면 연월을 파일에 맞추기"를 누르고, 화면이 맞으면 그대로 둔다. 신입(B팀)은 명단 아래 이름 칸에 B만 적은 구분 행 밑에 이름을 적는다(양식에 예시 행이 있다). 잘못 올렸으면 "반영 해제"로 취소한다. 문제가 있는 파일은 업로드 칸 아래 빨간 글씨로 무엇이 왜 문제인지 계속 표시되고, 그 전에 올린 파일이 있으면 "⚠ 새 파일은 반영되지 않았습니다 — 이전에 올린 입력①(…)을 계속 씁니다"가 붙는다 — 이때 버튼은 "오류 지우기(이전 파일 유지)"(오류 문구만 지움)와 "이전 파일도 해제" 둘이다(이전 파일이 없으면 "오류 지우기" 하나).
    가능근무 칸에는 근무코드 말고 세 가지를 더 적을 수 있다 — 지정(근무인력 표의 '지정' 인원으로 셀 사람), 2N·3N(야간을 며칠씩 묶어 설지, 안 적으면 2N). 3N은 그 사람의 월 야간이 상한(기본 6회)으로 고정된다. 예: D,E,N,지정 · D,E,N,prn,3N.
    '야간리더' 칸(가능근무 바로 옆) — 밤을 맡길 수 있는 분에게만 O. 밤에는 숙련도 4 이상이 한 명은 꼭 있어야 하는데(필수), 리더가 주간 상근인 병동은 밤에 세울 Lv4·Lv5가 모자라 매일을 못 채운다. 표시한 분이 선 밤은 숙련도와 상관없이 그 조건을 채운 것으로 본다. 야간 횟수가 늘지는 않고, 안 쓰면 전부 비워 두면 된다(지금까지와 동일). 몇 명? 한 달 날수 ÷ 6이 최소선(30일이면 5명) — 밤을 서는 Lv4·Lv5가 있으면 그만큼 뺀다. 샘플 명단에 그대로 적혀 있고, 출력②에도 다시 적혀 나가 다음 달로 이어진다.
  4. 근무표 생성 클릭 — 진행 게이지가 뜨고, 40명대는 3~10초, 100명 병동도 12초 안팎이면 끝난다(v0.87 실측). 느린 것은 인원이 많아서가 아니라 최소인력이 빠듯해서다 — 그런 달은 "인원이 빠듯해 평소보다 오래 걸립니다"가 뜬다. 지정 가능자가 빠듯하면 누른 직후 알림이 뜨고 결과 표 위에도 ⚠로 남는다. 다시 눌러도 처음부터 새로 계산한다(이어서 하지 않음). 빨간 "필수 위반"이 남는 달에는 생성 버튼 아래 "🔍 꼼꼼히 만들기"를 켜고 다시 생성한다 — 평소 3개 만들어 고르던 근무표를 9개 만들어 고른다(일반 생성 약 10초 대비 약 3배인 30초, 빠듯한 달은 몇 분. "여기까지 결과로 멈추기"로 중간에 멈출 수 있다).
  5. 결과 확인("2. 근무표 출력") — 그리드 + 검증 요약이 뜬다. 빨간 배너 = 필수 위반이 남음, 이대로 쓰지 말 것(칸을 고치거나 인원·근무인력을 바꿔 다시 생성) · 노란 배너 = 필수는 다 지켰고 추가 검토 항목만 남음(한 번 보고 넘어간다). 프로그램 오류가 아니라 "이 조건으로는 어디까지 됐다"는 정직한 표시다. 검증 요약의 항목을 누르면 그 칸으로 가고, 날짜 머리칸을 누르면 그날 병동, 이름을 누르면 그 사람의 한 달이 뜬다. 표 바로 위 띠(필수 위반 n · 추가 검토 n · ⬇ 다운로드 · ✎ 편집 n)를 누르면 그 자리로 간다. 오른쪽 패널 아래쪽 "자세히 보기"(처음엔 접힘)에 수정 전 점검·시도 점수표·처리 로그가 있다. 패널 맨 아래 "월간 근무 보고(HTML) 받기"는 확인할 항목을 한 파일에 모아 준다(자세한 것은 상세 사용가이드).
    새로고침·뒤로가기로 결과가 날아가면 같은 탭에서는 입력 화면 맨 위 "직전 근무표가 있습니다" 카드의 "직전 근무표 복원"으로 같은 입력으로 다시 만든다(탭을 닫으면 그 기록도 사라진다). 표나 올린 입력이 있으면 떠나기 전에 브라우저가 한 번 묻는다.
  6. 필요하면 칸 클릭해서 수정 → (편집 목록 아래에 자동으로 뜨는 위반 안내 확인) → 재생성 적용. 고친 칸은 재생성해도 절대 안 바뀐다. 편집 중일 때만 오른쪽 패널 제목이 "편집 중 (미적용)"으로 바뀌고 다운로드 버튼이 잠깐 비활성화된다 (아무것도 안 고쳤으면 그냥 "편집"이라고만 뜬다).
  7. 다운로드 — 출력①"월간근무표"·출력②"연간근무표" 둘 다 받아 보관한다(파일 이름은 출력1_월간근무표_…·출력2_연간근무표_…). 출력②를 다음 달 입력②으로 그대로 재사용하면 이월정보·누적 통계가 자동으로 이어진다(인원 순서는 파트장 맨 위 + 원본 입력 순서 그대로, 화면·파일 둘 다 고정돼서 나온다). 출력②를 받으면 다운로드 아래에 "다음 달 준비" 카드가 떠서 연월 → 입력② 칸에 출력② → 새 입력① 순서를 짚어 준다.
  8. 엑셀에서 고쳤다면 "수정 엑셀 파일 업로드" — 받은 출력①을 엑셀에서 고쳐 그대로 올리면 다시 계산하지 않고 그 값이 화면에 들어오고 바뀐 칸은 고정된다("재생성 적용"은 표 전체를 다시 짜서 엑셀에서 맞춘 배치가 사라진다). 근무 칸만 고치고 행은 건드리지 말 것 — 사람을 빼거나 더한 파일, 다른 달 파일은 반려된다. 올린 직후에만 "① 즉시 다운로드"(고친 그대로)와 "② 재생성 후 다운로드" (고정 안 한 칸은 바뀔 수 있음) 두 갈래가 뜬다.

처음 쓰는 달의 첫 작업 — 샘플을 우리 병동으로

화면은 처음에 샘플 병동(설정·근무인력·명단)으로 채워져 있고, 입력①을 안 올리면 샘플 명단으로 근무표가 나온다.

  • ① 그대로 "근무표 생성"을 한 번 눌러 화면 흐름을 본다
  • ② 입력① 옆 "양식(다운로드)"을 받아 이름·직급·숙련도·가능근무·야간리더를 우리 명단으로 채워 "업로드"
  • ③ 근무정보·근무인력을 우리 병동 값으로 고친다 — 한 번 고치면 이 브라우저에 기억된다

그 뒤 다시 "근무표 생성". 입력②는 첫 달엔 없어도 된다. 처음 연 기기에서는 생성 버튼 위에 같은 세 단계가 "처음이면 이 순서로" 카드로 뜨고, 하면 저절로 체크된다(다 끝내거나 "닫기"를 누르면 다시 안 뜬다).

입력 구성 — 화면 설정과 파일 2종

어디에내용필수
설정·근무인력화면에서 직접 입력(브라우저에 저장됨). 공휴일·월신청상한은 없음(코드가 자동 처리)화면
입력①인원(직급·숙련도·가능근무·야간리더·비고·전입·전입일)+원티드표(근무/휴무 신청) — 양식은 매번 그 달 기준 자동생성첫 달 필수(명단), 이후 신청 있으면

출력 파일 2종

파일내용
출력① 월간근무표완성된 그 달 근무표. 병원 OCS 원본과 같은 모양의 엑셀이고, 잔휴·D/E/N·야간편차 등 계산열도 함께 들어있다. 부서 배포·기록용.
출력② 연간근무표이번 달까지 반영된 누적 통계·연간 그리드 갱신본. 그대로 다음 달 입력②이 돼서 이월정보·형평성 지표가 매달 이어진다. 맨 아래에 날짜별 D·E·N·prn 인원과 레벨 통계가 붙는다(빨간 미달 표시는 출력①에만 — 연간 그리드는 달마다 기준이 다를 수 있어서).

화면 색상 · 테두리

D E N NK prn 8A/9A 연차 S/ 수면오프 TW 군
  • 화면 범례에는 이달 표에 나온 코드만 뜬다. 빗금 진함 = 고정 칸(수정 불가), 빗금 옅음 = 맞교환으로만. 이름 옆 지 = 지정 가능자, 밤 = 야간리더
  • / = 일반오프, X = 원티드오프(신청한 쉬는 날) — 둘 다 "쉬는 날"이고 표기만 다름. S/ = 야간 뒤 수면오프(쉬는 날)
  • 빨간 실선 = 확정(고정) 칸 — 재생성해도 안 바뀜
  • 주황 점선 = 고쳐놓고 아직 "재생성 적용"을 안 누른 칸
  • 그리드 오른쪽 ®·ⓡ 열은 OCS 형식 계산열이라 이 화면에서는 항상 빈칸(파일에만 값이 채워짐)
  • 일반 인원 아래 "B팀(신입)" 구분행 = 엔진이 배정하지 않는 신입. 칸을 눌러 근무를 직접 넣고, 재생성해도 값이 남는다. 인원 수·레벨 통계에는 안 잡힌다.
  • 그리드 맨 아래 날짜별 인원 = 이달 표에 나온 근무 코드마다 한 줄(D·E·N·NK·8A·prn·연차·OFF…), 그날 그 코드인 사람 수(파트장 제외). 최소인력 기준은 D·E 줄, 밤은 N+NK 줄(야간전담이 없으면 N 줄), prn은 prn 합계 줄(반일 0.5명)에 걸린다. 근무인력 표의 '지정'이 0보다 큰 병동은 "지정 인원" 줄이 붙는다. 못 미치면 빨강, 넘치면 노랑이고, 칸에 마우스를 올리면 기준값이 보인다. 점선 아래는 최소인력에 안 세는 코드(교육·휴가·OFF). 칸을 고치면 즉시 다시 센다. 출력① 엑셀 맨 아래도 같은 줄이 수식으로 붙는다. 그 아래 "D 레벨·E 레벨·N 레벨" 3행 = 근무조마다 그날 선 사람들의 평균 숙련도 (섞어서 하나로 내면 어느 조가 얇은지 안 보여서 조별로 나눴다 — 숙련도 4 이상이 한 명도 없는 조는 칸이 빨개진다. 야간은 "야간리더" 칸에 O를 적은 사람이 서 있으면 숙련도와 무관하게 충족으로 보므로 빨개지지 않는다 — 낮에는 그 예외가 없다). 이어지는 "Lv4-5·Lv1-3" 2행 = 그날 숙련도 4~5인 사람과 1~3인 사람의 인원수(칸을 고치면 즉시 갱신)

꼭 기억할 것

  • 브라우저에 계속 남는 것은 근무정보·근무인력 설정뿐이다 — 직전 근무표와 올린 입력①②는 같은 탭 안에만 있어 새로고침 뒤 "직전 근무표 복원"으로 되살릴 수 있지만 탭을 닫으면 사라지므로 확정본은 꼭 엑셀로 다운로드해 보관.
  • "입력으로 돌아가기"를 누르면 지금까지의 편집이 전부 초기화된다.
  • 파트장 칸은 D·E·N·NK·prn만 막고, 연차·병가·교육·8A 등은 눌러 넣을 수 있다. B팀(신입) 칸도 눌러 근무를 직접 넣는다(엔진은 배정하지 않고, 인원 집계에도 안 넣는다).
  • 연속 오프는 14일까지만 받는다 — 원티드표에 15일 넘게 이어 적으면 15일째부터 반려된다(앞의 14일은 반영). 더 쉬어야 하면 구간을 나눠 적는다.
  • 같은 날에 신청이 몰리면 명단 순서가 아니라 ① 그 달 원티드를 적게 적은 사람 ② 그날 조의 숙련도가 고르게 되는 쪽 순으로 받는다. 밀린 건은 사유가 붙고, 노란 목록에 날짜별로 누가 몇 명 밀렸는지 뜬다.
  • 8A·9A·10A는 주말·공휴일에도 넣을 수 있다(자동으로 채워지는 것만 평일). 간호사도 가능근무에 8A를 적으면 설 수 있고 prn 인원으로 센다.
  • 업로드 파일의 "안내" 시트는 지우지 않고 그대로 올려도 된다.
  • "근무표 생성"을 다시 누르면 처음부터 새로 계산한다(이전 시도와 이어지지 않음).
  • D와 E는 사람마다 비슷한 비율로 나뉜다(한 사람은 D만, 다른 사람은 E만 서지 않게). 원티드로 신청한 칸과 직접 고친(고정) 칸은 그대로 둔다.
  • 새 버전이 배포되면 화면 맨 위에 "새 버전이 있습니다" 띠가 뜬다 — "새로 고침"을 누른다(만들던 표는 "직전 근무표 복원"으로). 최신 화면인지는 버전 옆의 시각으로 본다 — 같은 버전 안에서 고친 것이 배포되면 숫자는 그대로고 시각만 바뀐다. 배포 안내의 시각보다 이르면 새로고침 한 번.

간호사 근무표 자동생성 — 원페이지 요약

v0.4 · 리더용 1장 요약

사용 순서

  1. 링크 접속 — 설치 없이 브라우저로 열면 끝. 처음엔 샘플 데이터가 이미 채워져 있다.
  2. 입력 파일 올리기 — 병동인력표(입력①)만 있으면 시작 가능. 각 업로드 칸 옆 양식 버튼으로 40명 규모 실제 예시(설명 포함)를 받아 우리 병동 값으로 고쳐 올리면 된다.
  3. 최소인력·원티드 확인 — 화면 하단에서 요일별 필요 인원, 직원 신청 내역을 검토·수정한다.
  4. 근무표 생성 클릭 — 인원 많으면(40명대) 최대 2분 정도 걸릴 수 있다. 창 닫지 말 것.
  5. 결과 확인 — 그리드 + 검증 요약이 뜬다. 하드 위반이 남아도 프로그램 오류가 아니라 "이 조건으로는 100% 못 지켰다"는 정직한 표시다(자세한 이유는 아래 빠른시작가이드 참고).
  6. 필요하면 칸 클릭해서 수정 → 피드백 확인 → 재생성 적용. 고친 칸은 재생성해도 절대 안 바뀐다.
  7. 다운로드 — "근무표 엑셀"을 받아 부서에 배포. "인원표(갱신본)"은 보관해뒀다가 다음 달 입력④로 다시 올리면 누적 통계가 이어진다.

입력 파일 4종

파일내용필수
입력①설정+인원+최소인력필수
입력②전월 확정 근무표(이월용)선택
입력③원티드표(근무/휴무 신청)선택
입력④인원표(다월 자동연동)선택

화면 색상 · 테두리

D E N NK prn 8A 연차
  • 빨간 실선 = 확정(고정) 칸 — 재생성해도 안 바뀜
  • 주황 점선 = 아직 적용 안 한 편집(스테이징)

꼭 기억할 것

  • 브라우저 전용판은 데이터가 그 기기·그 브라우저에만 저장된다 — 확정본은 꼭 엑셀로 다운로드해 보관.
  • "입력으로 돌아가기"를 누르면 지금까지의 편집이 전부 초기화된다.
  • 업로드 파일의 "안내" 시트는 지우지 않고 그대로 올려도 된다.

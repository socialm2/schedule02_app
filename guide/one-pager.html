SMC Fair Shift — 원페이지 요약

v0.8 · 파트장용 1장 요약

사용 순서

  1. 링크 접속 — 설치 없이 브라우저로 열면 끝. 입력 화면("1. 기본 사항 입력") 상단에는 입력 데이터가 서버로 전송되지 않고 이 브라우저에서 처리된다는 안내(공용 기기·화면공유·다운로드 파일 주의 포함)가 항상 표시된다. 처음엔 샘플 데이터가 이미 채워져 있다.
  2. 설정·근무인력 입력 — 화면에서 직접 친다(올릴 파일 없음). 연월·월최대야간·연속근무제한· 야간목표와 근무별(D/E/N/prn) 요일별 필요 인원을 채우면 이 브라우저에 저장돼 다음에 열 때 그대로 뜬다. 되돌리려면 근무인력 표 아래 저장된 설정 지우기. 공휴일·월신청상한 칸은 없다 — 공휴일은 코드가 2040년까지 자동으로 계산해서 채운다.
  3. 입력② 올리기 — 인원(직급·숙련도·가능근무·비고·전입·전입일)과 원티드 신청을 파일 하나로 받는다. 업로드 칸 옆 양식 버튼으로 현재 명단·연월에 맞는 양식을 받아 채워 올린다. 날짜 칸은 OCS에서 그대로 복사해 붙여넣어도 되고, 이 파일의 연·월이 곧 만들 달이라 올리면 화면 연월이 맞춰진다. 잘못 올렸으면 "반영 해제"로 취소한다(업로드가 실패했을 때도 이 버튼이 뜨고, 누르면 오류 문구가 지워진다). 문제가 있는 파일은 업로드 칸 아래 빨간 글씨로 무엇이 왜 문제인지 계속 표시된다.
  4. 근무표 생성 클릭 — 진행 게이지가 뜨고, 40명대 병동 기준 10초 안팎이면 끝난다. 인원이 훨씬 많은 병동(50명 이상)은 그보다 오래 걸릴 수 있다. 다시 눌러도 처음부터 새로 계산한다(이어서 하지 않음).
  5. 결과 확인("2. 근무표 출력") — 그리드 + 검증 요약이 뜬다. 상황에 따라 빨간(구조적으로 못 채움)· 노란(최선노력 규칙만 남음)·시간초과 배너가 뜬다 — 프로그램 오류가 아니라 "이 조건으로는 어디까지 됐다"는 정직한 표시다(자세한 이유는 상세 사용가이드 참고).
  6. 필요하면 칸 클릭해서 수정 → 피드백 확인 → 재생성 적용. 고친 칸은 재생성해도 절대 안 바뀐다. 편집 중일 때만 오른쪽 패널 제목이 "편집 중 (미적용)"으로 바뀌고 다운로드 버튼이 잠깐 비활성화된다 (아무것도 안 고쳤으면 그냥 "편집"이라고만 뜬다).
  7. 다운로드 — 출력①"월간근무표"·출력②"연간근무표" 둘 다 받아 보관한다. 출력②를 다음 달 입력③으로 그대로 재사용하면 이월정보·누적 통계가 자동으로 이어진다(인원 순서는 파트장 맨 위 + 원본 입력 순서 그대로, 화면·파일 둘 다 고정돼서 나온다).

입력 파일 3종

파일내용필수
설정·근무인력화면에서 직접 입력(브라우저에 저장됨). 공휴일·월신청상한은 없음(코드가 자동 처리)화면
입력②인원(직급·숙련도·가능근무·비고·전입·전입일)+원티드표(근무/휴무 신청) — 양식은 매번 그 달 기준 자동생성선택
입력③연간근무표(이월정보+다월 자동연동). 처음 쓰는 달이면 OCS 지난달 근무표도 가능(누적 통계는 0에서 시작)선택

출력 파일 2종

파일내용
출력① 월간근무표완성된 그 달 근무표. 병원 OCS 원본과 같은 모양의 엑셀이고, 잔휴·D/E/N·야간편차 등 계산열도 함께 들어있다. 부서 배포·기록용.
출력② 연간근무표이번 달까지 반영된 누적 통계·연간 그리드 갱신본. 그대로 다음 달 입력③이 돼서 이월정보·형평성 지표가 매달 이어진다.

화면 색상 · 테두리

D E N NK prn 8A/9A 연차 S/ 수면오프 TW 군
  • / = 일반오프, X = 원티드(신청·지정) 오프 — 둘 다 "쉬는 날"이고 표기만 다름
  • 빨간 실선 = 확정(고정) 칸 — 재생성해도 안 바뀜
  • 주황 점선 = 아직 적용 안 한 편집(스테이징)
  • 그리드 오른쪽 ®·ⓡ 열은 OCS 형식 계산열이라 이 화면에서는 항상 빈칸(파일에만 값이 채워짐)
  • 일반 인원 아래 "B팀(신입)" 구분행 + 빈칸 행 = 스케줄링 관여 안 함, 부서에서 직접 배정
  • 그리드 맨 아래 "레벨평균·Lv4-5·Lv1-3" 3행 = 그 날짜에 근무하는 인원의 평균 숙련도·고랩·저랩 인원수(날짜별, 칸 수정 시 즉시 갱신)

꼭 기억할 것

  • 브라우저 전용판은 데이터가 그 기기·그 브라우저에만 저장된다 — 확정본은 꼭 엑셀로 다운로드해 보관.
  • "입력으로 돌아가기"를 누르면 지금까지의 편집이 전부 초기화된다.
  • 파트장 칸은 항상 8A로 고정돼 화면에서 편집할 수 없다(의도된 동작).
  • 업로드 파일의 "안내" 시트는 지우지 않고 그대로 올려도 된다.
  • "근무표 생성"을 다시 누르면 처음부터 새로 계산한다(이전 시도와 이어지지 않음).
